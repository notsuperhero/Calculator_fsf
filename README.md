# Math Calculator

A simple, stylish calculator built with HTML, CSS, and JavaScript.

## Recent Updates

- **Project Initialization**: Initialized the project with a `package.json` and installed `vite` for a modern development experience.
- **UI Fixes**: Corrected the alignment of the '0' button by adjusting the CSS aspect ratio.

## Getting Started

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Run the development server**:
    ```bash
    npm run dev
    ```

3.  **Build for production**:
    ```bash
    npm run build
    ```
